## 📋 Sobre o Projeto

Este site oferece dois testes baseados em critérios da psicologia:

1. **Descubra se você é Vítima de Narcisismo** – identifica padrões de relacionamento tóxico.
2. **Descubra se você é Narcisista** – autoavaliação de traços de personalidade.

Os testes são baseados em:
- Inventário de Personalidade Narcisista (NPI-16)
- Critérios do DSM-5 para Transtorno de Personalidade Narcisista
- Sinais comuns em relacionamentos com narcisistas

## ⚠️ Aviso Legal

Este site é uma ferramenta **informativa e educacional**. Não substitui uma avaliação profissional. Somente um psicólogo ou psiquiatra qualificado pode diagnosticar o Transtorno de Personalidade Narcisista (TNP). Os resultados aqui apresentados são apenas indicativos.
